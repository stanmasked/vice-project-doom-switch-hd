# Stage360 — immutable cross-archive continuity analysis protocol

Stage360 is a **retrospective, source-reauthenticated** test of ORIGINAL RGB already captured under Stage354 (495–519), Stage350 (520–544), Stage359 (545–559), and Stage351 (560–584). **Not a new blinded or preregistered original holdout.** Its cross-archive boundary joins (519→520, 544→545, 559→560) have not previously been evaluated under the rule below. The exact source windows, independent original archive SHA manifest pins and all thresholds are frozen here before running this new test; do not retune after seeing the result.

## Original provenance gate (owner private only)

1. Require four distinct, owner-private ZIP archives, from the four already recorded original read-only FCEUX v2.6.5 (NewPPU=0) captures. Require a distinct, independently previously pinned JSON source manifest with SHA256 verification for each, original stage IDs 354,350,359,351 respectively, the exact 25/25/15/25 original frame ranges and original `newppu=0`, `original_readonly=true`. Verify CRC of the four ZIPs and individually SHA-256 recheck **32,32,22,32** original source members from each source manifest. No archived NES ROM or FM2 permitted. Capture must include `COMPLETE.txt` and the full prior-sealed authentic 261-frame Stage335 CPU + Stage341 native PPU traces, identical SHA over all four archives; independently verify 261 exact frame-begin anchors each. Recheck original indexed sample probe files and 3 indexed palette planes per archive; do not substitute synthetic pixels in this original evaluation.
2. Compare two original native 256×240 whole GD RGB images **across** each boundary: **519→520, 544→545, 559→560**, requiring distinct original source captures (one image from each adjacent archive) and exact per-member pinned digests.
3. Separately classify within Stage350 source pairs **520→521 through 543→544**, to identify how its previously archived observed **7 x +3 and 17 x +4** scene shifts are ordered; **do not** claim this ordering is a fresh holdout.

## Frozen RGB + original first scroll Y classifications

Retain original half-open environmental ROIs (x0–52 or 195–255, y20–98 and 98–175). For each pair each ROI independently scores all 49 signed vertical shifts `-24..+24`, pixel mismatch by *any unequal RGB channel* over correctly cropped overlapping source ROIs. A region is confident if lowest error ≤`0.16` and runner-up gap ≥`0.045`. Four confident agreeing => strict 4/4; exactly three confident agreeing => qualified 3/4; two or more conflicting confident => conflict, **not success**; otherwise inconclusive. An identical/flat original image is not uniquely textured motion evidence and stays inconclusive even with register source.

For each qualified image pair, **independently** compare the measured image shift to minus signed modulo-240 difference of frame-local verified first second-phase CPU $2005 vertical scroll value, with original classic PPU native line-zero temp Y, live RAM0D, frame anchors and no intervening address writes all verified. Never carry forward missing CPU writes, never use subsequent writes as if first. Mark register comparison unsupported if either frame lacks a full original anchor, not zero. If mismatch, preserve as source contradiction. Classify boundary and within-window pairs separately.

Cross-boundary continuity scientific status is **observational** even if every pair passes; no global vehicle speed, car physics, hardware PPU dot timing, complete camera law, all stages/levels. Keep original Stage355 380–404 full image-motion result **FAILED/INCONCLUSIVE**, Stage357 five inconclusive pairs unchanged and Stage359 +4 valid finite result unchanged. Do not merge Draft PR #99.
